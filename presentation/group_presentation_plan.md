## 3. 第②部分：三个模型的基本原理（6:30）

### 第 3 页：三个模型总览（B，0:20）

| | ARIMA | ETS | UC |
|---|---|---|---|
| 视角 | 差分后的自相关 | 指数平滑的成分 | 状态空间分解 |
| 关键参数 | p,d,q / P,D,Q | 平滑参数 | 各成分方差 |
| 典型设定 | Airline (0,1,1)(0,1,1)₁₂ | AA12 / AN / NN | LLT / LLT12 |
| 本案例 | 非季节 ARIMA | NN（仅水平） | LLT |

### 第 4 页：ARIMA 原理（B，1:30，简）

> 课内内容，只回顾关键点。

- 平稳性与差分：`d` 阶差分、季节差分 `D`
- AR / MA：用过去值和过去误差解释当前值
- 季节 ARIMA：`(p,d,q)(P,D,Q)s`
- Airline 模型：`(0,1,1)(0,1,1)₁₂`，论文中的基准
- 一句话：**差分去趋势 + 用相关结构预测**

### 第 5 页：ETS 原理（A，1:40）

- 三个成分：水平 `l`、趋势 `b`、季节 `s`
- 加法结构：`y_t = l_{t-1} + b_{t-1} + s_{t-m} + ε_t`
- 平滑参数 `α, β, γ` 控制更新速度
- 模型代码：`AA12`（趋势+季节）、`AN`（仅趋势）、`NN`（仅水平）
- 和 ARIMA 的区别：ETS 逐期更新成分，不需要差分
- 本案例为什么用 NN：消费序列没有稳定趋势

### 第 6 页：UC 原理（一）：状态空间与 LLT（C，1:30）

> 本次重点，从这里开始放慢。

- 状态空间形式：观测方程 + 状态方程
- 局部线性趋势（LLT）：
  - 水平：`l_t = l_{t-1} + b_{t-1} + η_t`
  - 斜率：`b_t = b_{t-1} + ζ_t`
- 每个成分都有自己的扰动项和方差
- 相比 ETS：UC 把成分写成显式的随机过程，可解释性更强

### 第 7 页：UC 原理（二）：Kalman 滤波与成分分解（C，1:30）

- Kalman 滤波：逐期"预测—更新"状态
- 输出：水平的平滑估计、斜率的平滑估计、不规则项
- 论文用它提取 CO₂ 长期趋势（Fig.3）
- 本案例设定：`LLT`（无季节），一步滚动 + 最终五步
- 一句话：**UC 的优势不是预测精度，而是能把趋势单独拿出来解释**

## 4. 第③部分：消费预测对比结果（C，3:50）

### 第 8 页：数据与统一协议（C，0:50）

- 从 CO₂ 换到个人消费：三人各自的支付宝 + 微信账单
- 目标：`个人总支付`（毛额）；排除转账、红包、亲属卡
- 自然周，108 个训练周

| 控制项 | 设定 |
|---|---|
| 滚动 | 扩展窗口，30 折，一步预测 |
| 最终预测 | 108 周重新估计，一次预测 5 周 |
| 十月累计 | 4/7·f1 + f2 + f3 + f4 + 6/7·f5 |
| 季节 / 变换 | 不加季节，不做 Box-Cox |
| 估计 | CML |
| 指标 | MAE、RMSE、sMAPE、MASE |

> 强调：**同一份数据、同一套协议，只换模型。**

### 第 9 页：30 折滚动一步结果（C，1:10）

- 图：`results/figures/case_summary/case_mase_by_model.png`

**已知 ETS 数字**

| 模型 | A | B | C |
|---|---|---|---|
| ETS-NN | 0.755 | 1.068 | 1.166 |
| ETS-AN | 1.199 | 1.151 | 1.275 |
| UC-RW | — | 1.020 | — |

- 要点：ETS-NN 最好；AN 全面更差；UC-RW 与 ETS-NN 接近

### 第 10 页：十月累计结果（C，0:50）

- 图：`results/figures/case_summary/case_oct_error.png`

**已知数字**

| 数据 | ETS-NN | ETS-AN | UC-RW |
|---|---|---|---|
| A | 58.1% | 96.3% | — |
| B | 40.3% | 79.6% | **3.89%** |
| C | 40.9% | 77.5% | — |

- 要点：单次五步预测对最后几周极敏感；UC-RW 在 B 数据上明显更稳

### 第 11 页：三模型对比与结论（C，1:00）

1. 一步滚动和最终五步排序不一致，**两种任务不能混**
2. 消费序列的主要可预测成分是**水平**，不是趋势
3. 简单基准（朴素 / 三期移动平均）在部分数据上不输复杂模型

**局限**

- 十月结果已公开，新增模型属于事后对照
- 112 周不足以估计年度季节
- 三人数据来源不同，绝对金额不可横比

**收尾句**

> "在个人消费数据上，简单、稳定的水平模型往往比复杂的趋势模型更可靠。"
