# UC协议及数值稳定性补充实验

本次预先限定四组方案，均使用作者原有modelUC(x, [], 'LLT12',24)，不改变结构、阶数、估计方法或异常值阈值，不手工指定初值。不根据论文误差搜索lambda。四组各220轮，合计21120条预测；旧结果完整保留。

1. 滑动480月，每轮只用训练集估计Box-Cox lambda。
2. 扩展窗口，固定首轮训练lambda。
3. 滑动480月，固定首轮训练lambda，并对变换后的训练序列中心化、除以当轮样本标准差。
4. 滑动480月，固定A的0.2461，并做同样标准化；该组保留A参数前视风险，仅作协议诊断。

标准化只用训练数据：x=(ty-mean(ty))/std(ty)，UC预测先乘回标准差、加回均值，再逆Box-Cox到ppm。仿射缩放在理论上不改变线性高斯UC模型族，但有限精度实现、默认初始化和优化路径未必具有严格尺度不变性；若预测变化，应视为数值实现敏感性的证据，不等于更换了新阶数模型。

所有指标均为220轮、前12或24步累计平均；sMAPE单位为百分数。扩展窗口MASE使用当轮全部训练数据的分母，比较表另列相同预测改用480月分母的诊断列，不能将两种尺度混为同一正式结果。

## 与论文的差异

- 滑动逐轮lambda：1年/2年sMAPE差值为+0.015203 / +0.029406个百分点，MASE差值为+0.039691 / +0.073405。
- 扩展固定首轮lambda：1年/2年sMAPE差值为+0.019410 / +0.028808个百分点，MASE差值为+0.079612 / +0.111808。
- 滑动首轮lambda标准化：1年/2年sMAPE差值为+0.011971 / +0.019232个百分点，MASE差值为+0.031461 / +0.047618。
- 滑动A_lambda标准化：1年/2年sMAPE差值为+0.006810 / +0.017212个百分点，MASE差值为+0.017994 / +0.041752。

标准化对照：

- 滑动首轮lambda标准化与同窗口同lambda未标准化结果相比，最大预测差异5.026728182 ppm，平均绝对预测差异0.226497271 ppm。
- 滑动A_lambda标准化与同窗口同lambda未标准化结果相比，最大预测差异6.234966986 ppm，平均绝对预测差异0.642559501 ppm。

论文全部八种期限（1至6、12、24步）的对照见table4_comparison.csv。以下统计仅说明按论文三位小数精度重现了多少个单元格，不作为参数搜索目标。

- 扩展固定首轮lambda：16个论文数值中有0个按三位小数一致。

- 滑动A_lambda标准化：16个论文数值中有2个按三位小数一致。

## 结论

在预先限定的四个补充方案中，滑动480月、固定首轮训练lambda并标准化，是无前视方案中四个年度指标都最接近论文的一组。它相对旧无前视固定lambda结果有所改善，但1年、2年均未达到论文三位小数精度。含A参数的标准化组四项指标更接近论文，仍有前视风险，不能因此优先作为正式无前视复现协议。

尺度对照只改变训练期的可逆仿射重标度，恢复ppm后预测仍明显变化，因此当前UC实现的默认估计或初始化对数值尺度敏感。此试验不能区分有限精度、优化停止准则、初值及状态初始化各自的贡献，也不能据此直接断定软件存在某一个已定位的缺陷。

逐轮lambda和扩展窗口固定lambda未填平论文差距；前者两年结果与旧滑动固定首轮lambda接近，后者的MASE还受到扩展训练分母影响。由此，没有证据支持仅调整左边界、重估lambda或改方法标签就能精确重现Table 4。剩余差异需作者完整滚动设置及2019年实际计算环境进一步核对，不应继续针对Table 4目标搜索lambda或手工修改预测。


本次先做3轮检查并通过独立核验，再从有效检查点续跑；所有既有预测不重估。记录的MATLAB为26.1.0.3346908 (R2026a) Update 5、ECOTOOL为1.0；依赖指纹、实际模型输入、参数、完整估计表、恢复尺度参数及耗时均在checkpoint.mat。

本次指标是对同一历史样本的补充探索；不能因为某组最接近Table 4就断言其等同原作者协议，也不能将探索后选出的方案当作独立测试集验证。论文未公开完整220轮滚动程序，UC后端是加密P代码，初值和内部优化的剩余差异尚不能唯一定位。

作者版本核对：2020、2021及2023工具箱包中的modelUC.m与modelUC0.p指纹一致，也与本机一致。2020包和当前核对包各144个代码文件，逐文件哈希比较仅vscatter.m和mmVAR.p不同，UC入口、后端及已识别的UC辅助代码没有变化。详见author_versions.txt；这削弱了“换一个已公开历史UC后端就能改善”的解释，但加密代码不能完整追踪依赖，不能证明整个调用链等效，也不确认2019年实际MATLAB优化器及完整滚动环境。未替换本机工具箱。
