# 项目计划与小组分工

## 1. 项目目标

本项目为三人小组时间序列分析课程作业。

核心任务是复现Diego J. Pedregal（2019）论文 *Time series analysis and forecasting with ECOTOOL* 中的Mauna Loa大气CO₂浓度预测案例。

复现范围主要对应原论文第9～13页。

计划3天完成核心实验与12分钟汇报，最多使用5天。

本项目主要验证经典时间序列模型在真实CO₂浓度数据上的预测效果，不开展新的模型理论创新。

### 1.1 核心复现内容

1. 获取并检查Mauna Loa月度CO₂浓度数据。
2. 分析原始序列的长期趋势与季节性。
3. 完成必要的数据变换、差分及ACF/PACF分析。
4. 复现五种经典时间序列预测模型。
5. 生成未来24个月的预测结果。
6. 计算sMAPE和MASE评价指标。
7. 对照原论文Table 4分析结果。
8. 制作12分钟小组汇报PPT及演讲稿。

### 1.2 复现优先级

**必须完成：**

- 原始数据读取与检查。
- 原始序列分析。
- Airline SARIMA、Auto ARIMA、Seasonal Naïve预测。
- 对应预测误差计算。
- 实验结果分析。
- 完整PPT、演讲稿及彩排。

**争取完成：**

- ETS与UC模型复现。
- 220轮滚动预测。
- 与原论文Table 4进行严格数值对照。
- UC估计趋势与论文Fig.3的对照。

如时间不足，保留已验证的单次预测结果，明确区分已经完成与尚未完成的实验范围。

## 2. 分工原则

本项目采用**模型复现与分析任务并行分工**。

三位成员均承担实际时间序列分析任务，并独立运行自己负责的预测模型。

具体原则：

1. 每位成员至少负责一种预测模型。
2. 每位成员独立读取数据、运行模型、生成预测结果。
3. 每位成员计算自己模型的误差并解释结果。
4. 各成员的核心实验尽量不依赖其他成员的完成进度。
5. 使用共同的数据版本与实验协议保证结果可比。
6. 各成员分别制作自己负责部分的PPT与讲稿。
7. 最后集中整合代码、实验结果与汇报材料。

数据、模型、评价不再由三个人完全串行执行。

## 3. 共同实验协议

正式开始前，三人需要共同确认以下内容。

### 3.1 数据来源

统一使用ECOTOOL官方仓库提供的论文实验数据：

https://github.com/djpedregal/ECOTOOL

数据文件：

`dataPLOSpaper.mat`

原论文使用的Mauna Loa观测数据范围为1958年3月至2018年5月，频率为月度。

每位成员自行获取相同版本的数据，不需要等待成员A提供文件。

### 3.2 基本实验参数

论文给出的主要设置：

| 参数 | 设置 |
|---|---|
| 时间序列 | Mauna Loa月度CO₂浓度 |
| 单位 | ppm |
| 季节周期 | 12个月 |
| 初始训练样本长度 | 480个月 |
| 预测期限 | 24个月 |
| 正式实验形式 | 滚动预测 |
| 原文报告的滚动轮数 | 220轮 |

需要结合实际数据核对：

- 数据变量与列索引。
- 缺失值处理。
- 训练样本起止月份。
- 预测起点及预测目标月份。
- Box-Cox变换使用方式。
- 滚动预测的具体样本推进规则。
- 不同预测步长的有效评价样本。

原论文第11页给出`maunaLoa(25:504,5)`的示例索引，但应结合实际数据检查其时间对应关系。

三人确认统一设置后再开展正式模型比较。

### 3.3 模型与评价

各成员使用原论文对应的ECOTOOL函数进行复现。

预测结果统一保存为可检查的数据文件。

建议至少包含：

- 模型名称。
- 预测起点。
- 预测目标月份。
- 预测步长。
- 实际观测值。
- 预测值。

统一使用sMAPE和MASE评价预测效果。

模型预测结果应恢复到原始CO₂浓度尺度，确保不同模型之间的比较具有可比性。

各成员独立计算自己的模型指标，由成员C负责检查汇总。

## 4. 成员A：数据特征分析、ETS与Naïve

### 4.1 主要职责

负责原始数据分析，以及ETS和Seasonal Naïve两种预测方法的复现。

### 4.2 具体任务

**任务A1：数据读取与检查**

1. 获取原论文实验数据。
2. 检查MAT文件中的变量。
3. 确认Mauna Loa数据位置。
4. 核对观测起止时间、单位及缺失值。
5. 检查数据与原论文描述是否一致。

**任务A2：时间序列特征分析**

1. 绘制原始CO₂浓度时间序列图。
2. 复现原论文Fig.1的主要内容。
3. 分析长期上升趋势。
4. 分析一年周期的季节性变化。
5. 用数据和图表解释这些特征。

**任务A3：Seasonal Naïve模型**

1. 理解季节性朴素预测的原理。
2. 使用原论文对应的ECOTOOL函数。
3. 生成24个月预测结果。
4. 计算预测误差。
5. 分析该模型作为基准方法的作用。

**任务A4：ETS模型**

1. 理解指数平滑模型的基本原理。
2. 使用原论文AA12模型设定。
3. 生成24个月预测结果。
4. 计算sMAPE及MASE。
5. 与Seasonal Naïve比较。

**任务A5：结果分析**

重点分析：

- 原始CO₂序列的趋势和季节性。
- ETS对趋势及季节性规律的刻画。
- 季节性朴素模型的预测能力。
- ETS相较于基准模型是否有改善。
- 不同预测步长下的误差变化。

**任务A6：汇报材料**

负责PPT第1～4页，约3分30秒。

同时负责最终PPT排版与格式统一。

### 4.4 验收标准

## 5. 成员B：Airline SARIMA与Auto ARIMA

### 5.1 主要职责

负责论文中ARIMA相关方法的复现，重点研究差分、相关性结构、模型识别和预测。

### 5.2 具体任务

**任务B1：数据与模型准备**

1. 独立获取原论文数据。
2. 检查数据格式和实验样本范围。
3. 安装并验证ECOTOOL工具箱。
4. 确认ARIMA相关函数可以调用。

**任务B2：数据变换与模型识别**

1. 研究原文中的Box-Cox变换。
2. 按原文要求对序列进行差分。
3. 绘制差分后的ACF/PACF图。
4. 复现论文Fig.2的主要内容。
5. 分析相关性结构与模型设定之间的关系。

**任务B3：Airline SARIMA模型**

1. 理解Airline模型的结构。
2. 按论文指定的ARIMA(0,1,1)×(0,1,1)₁₂设定模型。
3. 使用ECOTOOL进行参数估计。
4. 生成24个月预测结果。
5. 计算sMAPE和MASE。

**任务B4：Auto ARIMA模型**

1. 使用ECOTOOL的自动识别功能。
2. 记录实际识别出的模型结构。
3. 与Airline模型结构比较。
4. 生成24个月预测结果。
5. 计算sMAPE和MASE。

**任务B5：结果分析**

重点分析：

- 为什么需要差分？
- ACF/PACF如何帮助理解模型结构？
- Auto ARIMA与Airline的模型结构是否一致？
- 两种模型的预测误差有什么不同？
- 模型预测能力如何随预测步长变化？

**任务B6：汇报材料**

负责PPT第5～7页，约4分30秒。

同时负责最终MATLAB代码整合及运行入口整理。

### 5.3 独立交付物

- 数据变换及差分分析结果。
- ACF/PACF图。
- Airline SARIMA模型代码。
- Auto ARIMA模型代码。
- 两种模型的参数及结构记录。
- 两种模型的预测数据。
- sMAPE、MASE评价结果。
- 模型比较结论。
- PPT第5～7页及演讲稿。

### 5.4 验收标准

成员B能够独立完成两种ARIMA模型的拟合和预测，理解差分及相关性分析的意义，并解释两种模型的识别结果和预测差异。
