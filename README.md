# ECOTOOL-Mauna-Loa-Reproduction

基于 MATLAB 与 ECOTOOL 的经典时间序列预测论文复现项目。

本项目为三人小组课程作业，复现 Diego J. Pedregal（2019）发表于 *PLOS ONE* 的论文 *Time series analysis and forecasting with ECOTOOL* 中的 **Mauna Loa 大气 CO₂ 浓度预测案例**。

我们将使用论文公开的数据及 ECOTOOL 工具箱，分析 CO₂ 浓度的时间序列特征，建立经典预测模型，并对照论文结果验证复现效果。

项目预计在 **3天内完成核心复现及汇报材料，最多使用5天**。最终进行12分钟的小组汇报。

## 2. 我们需要复现什么？

### 2.1 研究问题

利用Mauna Loa观测站1958年3月至2018年5月的月度CO₂浓度数据，回答：

1. CO₂浓度随时间呈现什么变化趋势？
2. 数据是否具有明显的季节性？
3. 经典时间序列模型能否准确预测未来24个月的CO₂浓度？
4. 不同预测模型的效果存在什么差异？
5. 我们的结果与原论文是否一致？

### 2.2 实验内容

按照以下顺序完成：

```text
获取并核对原论文数据
          ↓
绘制时间序列图
          ↓
分析趋势与季节性
          ↓
必要的数据变换与差分
          ↓
绘制ACF/PACF
          ↓
建立时间序列预测模型
          ↓
预测未来24个月
          ↓
计算sMAPE、MASE
          ↓
与论文结果比较
```

计划复现五种模型：

| 模型 | 说明 |
|---|---|
| Airline SARIMA | 季节性ARIMA模型，原文指定结构为 ARIMA(0,1,1)×(0,1,1)₁₂ |
| Auto ARIMA | 由ECOTOOL自动识别ARIMA模型 |
| UC | 不可观测成分模型，采用LLT12设定 |
| ETS | 指数平滑模型，采用AA12设定 |
| Seasonal Naïve | 季节性朴素预测，作为对照基准 |

原文还包含纯AR模型，但其专门实现未包含在公开工具箱中，因此暂不列为必须完成的内容。

### 2.3 复现完成标准

**基础复现（必须完成）**

- 成功读取原论文数据。
- 重现原始序列趋势和季节性分析。
- 完成差分及ACF/PACF分析。
- 至少完成Airline SARIMA、Auto ARIMA和Seasonal Naïve的预测。
- 输出24个月预测值及对应的误差评价。

**完整复现（争取完成）**

- 完成全部五种预测模型。
- 按照原论文设计进行220轮滚动预测。
- 计算不同预测步长的平均sMAPE和MASE。
- 与原论文Table 4比较并分析差异。

注意：单次预测和220轮滚动预测属于不同的实验设置。只有使用可比的滚动预测协议，才能对Table 4进行严格的数值复现比较。

## 3. 如何开始复现？

### 第一步：获取项目

三名成员可以通过Git克隆本项目：

```bash
git clone https://github.com/41423577arc-lab/ECOTOOL-Mauna-Loa-Reproduction.git
```

进入项目文件夹后，阅读：

- `README.md`：项目总体流程。
- `docs/project_plan.md`：成员分工、时间安排及汇报计划。
- `docs/reproduction_protocol.md`：原论文实验设置与复现要求。
- `data/README.md`：数据来源及准备说明。

### 第二步：准备数据（成员A）

1. 从作者的ECOTOOL仓库获取`dataPLOSpaper.mat`。
2. 检查MAT文件包含哪些变量，确认Mauna Loa数据的位置和数据格式。
3. 对照论文第10～11页的示例，核对观测时间、数据列、缺失值及样本索引。
4. 将确认后的数据文件放入`data/`目录，保留原始数据不变。
5. 使用MATLAB绘制原始序列趋势图和季节性分析图。
6. 将图表保存至`results/figures/`。

需要记录数据来源、下载日期、样本数量及预处理方式。

不要将NOAA最新更新的数据直接替代论文历史数据进行严格复现。

**完成标准：** 数据可以读取，时间索引和变量含义明确，至少生成一张正确的CO₂时间序列图。

### 第三步：准备MATLAB与ECOTOOL（成员B）

项目使用MATLAB和作者公开的ECOTOOL工具箱。

各成员可以使用自己电脑上的MATLAB，不要求安装在相同位置，也不预先限定所有人的MATLAB版本。

主要操作：

1. 下载官方仓库中的`ECOTOOL.mltbx`。
2. 按MATLAB提供的方式安装工具箱。
3. 检查`modelTF`、`modelAUTO`等核心函数是否可调用。
4. 使用原论文提供的函数调用示例，测试数据加载与模型预测。
5. 记录实际运行成功的MATLAB版本、ECOTOOL版本及必要的兼容性处理。

本仓库不包含ECOTOOL的完整第三方源码；应使用原作者提供的版本。

目前`src/`尚未包含实验脚本。完成首个可运行版本后，在README中补充准确的运行入口、必要输入与输出位置。

**完成标准：** 至少一个模型能够在真实数据上执行，并输出预测结果。

### 第四步：执行模型复现（成员B，A协助）

完成数据与环境准备后：

1. 按原文要求进行数据变换与差分。
2. 绘制差分后的ACF/PACF图。
3. 复现Airline SARIMA模型。
4. 运行Auto ARIMA，比较自动识别的模型结构。
5. 补充UC、ETS及Seasonal Naïve。
6. 使用统一的训练数据和预测区间，输出未来24个月预测结果。
7. 保存预测数据及对应图表。

每个模型至少记录模型名称、训练区间、预测起点、预测步长及结果文件。

模型预测值最终应转换至原始CO₂浓度尺度后再进行误差比较，具体变换和逆变换过程需遵循原论文及所用函数的实际行为。

### 第五步：评价预测结果（成员C，B协助）

使用实际观测值与模型预测值计算：

- **sMAPE**：对称平均绝对百分比误差。
- **MASE**：平均绝对缩放误差。

优先完成单次24个月预测的评价，再根据剩余时间实现原论文的220轮滚动预测。

结果分析应包括：

1. 不同模型在相同预测条件下的表现。
2. 预测误差随预测步长变化的情况。
3. 模型是否优于季节性朴素预测。
4. 本组实验与原论文Table 4的一致之处和差异。
5. 可能的差异来源，包括数据版本、模型设置和实验协议等。

将模型比较结果保存至`results/tables/`，图表保存至`results/figures/`。

**完成标准：** 预测值和实际值时间对应正确，评价指标可以复核，结论有实验结果支持。

## 4. 小组分工

| 成员 | 主要职责 | PPT与讲稿 |
|---|---|---|
| A | 数据准备、序列分析、PPT整合 | 第1～4页，约3分30秒 |
| B | MATLAB环境、模型复现、代码整合 | 第5～7页，约4分30秒 |

A统一PPT格式，B整合实验代码，C统一完整演讲稿。三人共同核对实验结果并参加最终彩排。

详细分工见[项目计划](docs/project_plan.md)。

| 时间 | 核心任务 | 当天验收 |

## 7. GitHub协作方式

每位成员在本地修改文件，完成检查后提交至GitHub。

开始工作前同步最新内容：

```bash
git pull
```

提交自己的修改：

```bash
git add <本次修改的文件路径>
git commit -m "简要说明完成的任务"
git push
```

协作要求：

- 尽量避免多人同时修改同一个文件。
- 提交前检查文件内容，确保不会覆盖其他成员的工作。
- 不提交个人账号、密钥、私人文件及无关缓存。
- 大型临时文件不直接提交。
- 重要实验修改应说明变更原因。
- 已完成的代码必须能够在对应的数据与环境下复现。
- 修改共享实验设置前，与其他组员确认。

当前项目采用简单的三人协作流程，无需额外搭建自动化开发系统。
