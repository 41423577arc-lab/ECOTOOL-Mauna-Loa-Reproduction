# 与 UC 组员协议对齐：控制变量清单（v2）

> 依据：UC 组员 2026-11-21 反馈
> 用途：三人用同一套实验条件跑不同模型
> 主实验：**自然周 × 个人总支付 × 无季节 × 无变换**

---

## 1. 主对照实验（唯一排名口径）

| 控制项 | 统一设置 |
|---|---|
| 数据文件 | `自然周.xlsx`，工作表 `02_UC直接建模` |
| 预测变量 | **`个人总支付_元`**（不是总收入、对外流出或常规支付） |
| 频率 | 自然周，周一至周日，每期 7 天 |
| 训练范围 | 2024-09-02 ～ 2026-09-27，共 108 个完整周 |
| 金额单位 | 人民币元；不改汇率、不改支出分类 |
| 异常支出 | **保留原始观测**，不删异常、不截尾 |
| 变换 | 不取对数、不标准化、**不做 Box-Cox** |
| 外生信息 | 不使用收入、节假日、消费分类 |
| 季节项 | **不加** |
| 滚动 | 扩展窗口，每折重新估计，**一步预测** |
| 初始窗口 | 前 78 周；训练长度依次 78、79、…、107 周 |
| 滚动目标 | 第 79 ～ 108 周，共 **30 折**；起始日 2026-03-02 ～ 2026-09-21 |
| 最终估计 | 用全部 108 周重新估计 |

> 月度、连续七天是**独立实验**，各自单独排名，不与自然周混在一起。

## 2. 滚动验证 vs 最终十月预测（最易混淆）

| | 滚动验证 | 最终十月预测 |
|---|---|---|
| 折数 | 30 折 | 1 次 |
| 每折步长 | **1 步** | **5 步** |
| 训练窗口 | 78～107 周，逐折扩展 | 固定 108 周 |
| 能否用新观测 | 每折可加入此前已发生的训练观测 | **不能**加入 10 月真实值 |
| 用途 | 比较模型稳定性 | 预测 10 月累计 |

### 最终预测规则

- 预测原点：最后训练周结束日 **2026-09-27**
- 不得利用 9 月 28–30 日的信息
- 从同一原点一次性预测 **后续 5 周**（第 109～113 周）
- 五周预测按天数权重合成 10 月累计：

| 周 | 覆盖 10 月天数 | 权重 |
|---|---|---|
| 第 109 周（09-28 起） | 10-01 ～ 10-04 | 4/7 |
| 第 110 周 | 10-05 ～ 10-11 | 1 |
| 第 111 周 | 10-12 ～ 10-18 | 1 |
| 第 112 周 | 10-19 ～ 10-25 | 1 |
| 第 113 周（10-26 起） | 10-26 ～ 10-31 | 6/7 |

累计预测 = `4/7·f1 + f2 + f3 + f4 + 6/7·f5`

## 3. 评价指标（完全统一）

设误差为「预测值 − 真实值」：

| 指标 | 定义 |
|---|---|
| MAE | 各预测期绝对误差的平均值 |
| RMSE | 各预测期平方误差平均后开平方 |
| sMAPE | 每期 `200×|误差|/(|预测|+|真实|)`，再平均；两者同时为 0 时该项记 0 |
| MASE | 每折用该折训练数据的 `mean(abs(diff(yTrain)))` 作分母，再对缩放后的绝对误差取平均 |
| 10 月绝对相对误差 | `abs(累计预测 − 十月真实)/十月真实 × 100%` |

> MASE 分母是**相邻一期差分**，不是 52 周季节差分，也不是用完整 108 周统一算一个分母。

## 4. 模型对应与调参规则

| UC | ETS |
|---|---|
| `modelUC(y,[],'RW',1)` | `modelETS(y,[],'NN',1,'CML')` |
| `modelUC(y,[],'LLT',1)` | `modelETS(y,[],'AN',1,'CML')` |

**模型参数不需要相同**（ARIMA 阶数、ETS 平滑参数、UC 方差本就不同）。需要统一的是：

- 只允许用训练期数据调参
- 使用相同的验证窗口
- 提前规定搜索范围
- **不能根据 10 月误差反复挑模型**
- 估计方法尽量统一为 CML，并记录实际使用的方法
