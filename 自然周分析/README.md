# 自然周周期分析

在 MATLAB 中运行本目录的 `run_all.m`，或依次运行 `step01` 至 `step04`。依赖 MATLAB Econometrics Toolbox、Statistics and Machine Learning Toolbox，以及原项目使用的 ECOTOOL；第三步保留原工具箱路径自动加载逻辑。

- 数据源：根目录 `data/自然周.xlsx` 的 `02_UC直接建模`、`03_周期统计`，共 112 个完整周期，每期7天。
- 日期口径：周一至周日；首尾不完整自然周已由源工作簿排除，代码不补齐或拼接。
- 训练：前108期（2024-09-02 至 2026-09-27）。只纳入结束日在2026-10-01之前的完整周期。
- 保留测试：从 2026-09-28 开始的后续 4 期，包括首个跨9/10月周期。四步均不读取测试金额，不将跨月周期拆分或折算为10月月度金额。
- 分析流程：训练期描述统计与结构图 → 总支付/常规支付 ACF、PACF、Ljung–Box、ADF → 两条序列各拟合 RW 与 LLT → 四模型残差诊断及探索性异常筛查。
- 为沿用原流程，ACF/PACF仍用8期，原序列LB用3/6/8期，残差LB用3/6期，ADF用0/1阶；图中一阶滞后代表7天。RW/LLT不额外添加季节项。
- 原工作簿“偶发支出剔除”作为总支付减常规支付的组成核对字段；不在本流程中重新剔除支出。
- 图表（PNG/FIG）、训练数据、模型缓存、诊断MAT及CSV均写入本目录的 `output/`，与月度及另一种周期分析隔离。
- 四步沿用原有分析范围。第三步内部保留下一期预测以核验工具箱字段，不进行测试集评价、滚动择模或最终预测区间发布。

修改数据后应从第一步重跑。数据日期范围变化时，应同步更新第一步完整日期核验和第三、四步训练日期核验，避免静默改变训练/测试边界。
