# ECOTOOL-Mauna-Loa-Reproduction

基于 MATLAB 与 ECOTOOL 的经典时间序列预测论文复现项目。

本项目为三人小组课程作业，复现 Diego J. Pedregal（2019）发表于 *PLOS ONE* 的论文 *Time series analysis and forecasting with ECOTOOL* 中的 **Mauna Loa 大气 CO₂ 浓度预测案例**。

我们将使用论文公开的数据及 ECOTOOL 工具箱，分析 CO₂ 浓度的时间序列特征，建立经典预测模型，并对照论文结果验证复现效果。

项目计划在 **3天内完成核心复现及汇报材料，最多使用5天**。最终进行12分钟的小组汇报。

## 2. 研究目标与复现范围

### 2.1 研究问题

利用Mauna Loa观测站1958年3月至2018年5月的月度CO₂浓度数据，回答以下问题：

1. CO₂浓度随时间呈现什么变化趋势？
2. 数据是否具有明显的季节性？
3. 经典时间序列模型能否准确预测未来24个月的CO₂浓度？
4. 不同预测模型的效果存在什么差异？
5. 本组复现结果与原论文是否一致？

### 2.2 核心实验流程

```text
获取并核对原论文数据
          ↓
绘制时间序列图
          ↓
分析趋势与季节性
          ↓
必要的数据变换与差分
          ↓
绘制ACF/PACF
          ↓
建立时间序列预测模型
          ↓
预测未来24个月
          ↓
计算sMAPE、MASE
          ↓
与论文结果比较
```

本项目计划复现五种模型：

| 模型 | 说明 | 负责人 |
|---|---|---|
| Airline SARIMA | 季节性ARIMA，ARIMA(0,1,1)×(0,1,1)₁₂ | B |
| Auto ARIMA | ECOTOOL自动识别ARIMA模型 | B |
| UC | 不可观测成分模型，采用LLT12设定 | C |
| ETS | 指数平滑模型，采用AA12设定 | A |
| Seasonal Naïve | 季节性朴素预测，作为对照基准 | A |

原论文还包含纯AR模型，但相关专门程序未包含在公开工具箱中，因此暂不列为必须完成的内容。

### 2.3 复现完成标准

**基础复现（必须完成）**

- 成功读取并检查原论文数据。
- 重现原始序列趋势与季节性分析。
- 完成差分及ACF/PACF分析。
- 至少完成Airline SARIMA、Auto ARIMA和Seasonal Naïve的预测。
- 输出24个月预测值及对应的误差评价。
- 完成12分钟汇报所需的PPT和演讲稿。

**完整复现（争取完成）**

- 完成全部五种模型的预测。
- 按照原论文设计进行220轮滚动预测。
- 计算不同预测步长的平均sMAPE和MASE。
- 与原论文Table 4比较并分析差异。
- 尝试复现UC模型的趋势估计结果及Fig.3。

注意：

单次24个月预测和220轮滚动预测属于不同实验设置。只有采用可比的滚动预测协议，才能与论文Table 4进行严格的数值对照。

本项目不涉及模型理论创新，主要目标是理解并复现论文中的实际时间序列分析流程。

## 3. 如何开始复现？

### 第一步：获取项目

三名成员通过Git克隆项目：

```bash
git clone https://github.com/41423577arc-lab/ECOTOOL-Mauna-Loa-Reproduction.git
```

进入项目目录后，阅读：

- `README.md`：项目总体说明与操作流程。
- `docs/project_plan.md`：成员分工、时间安排及验收标准。
- `docs/reproduction_protocol.md`：原论文实验设置与需要核对的事项。
- `data/README.md`：数据来源与准备要求。

### 第二步：准备统一的数据与实验环境

为了减少成员之间的等待，三人分别准备实验环境，不依赖某一位成员提供数据或完成代码后才能开始。

各成员独立执行：

1. 从ECOTOOL官方仓库获取`dataPLOSpaper.mat`。
2. 获取并安装作者提供的`ECOTOOL.mltbx`。
3. 检查MATLAB是否能够读取数据。
4. 检查ECOTOOL核心函数是否可以调用。
5. 核对数据变量、观测时间、缺失值及样本范围。
6. 按统一实验协议确定训练区间与预测区间。

各成员可以使用不同电脑及MATLAB版本，无需使用相同的安装路径。

为保证结果可比，必须统一：

- 原论文数据版本。
- 实际使用的变量及观测值。
- 训练样本选取规则。
- 预测起点和预测期限。
- 模型评价指标及计算口径。
- 预测结果使用的数值尺度。

原论文示例使用480个月的训练数据，预测未来24个月，季节周期为12个月。正式滚动实验描述为220轮预测。

论文中的数据索引、训练截止日期及滚动预测方式需要结合原始数据进一步核对，不能直接混用不同实验设置。

各成员记录实际使用的MATLAB版本、ECOTOOL版本及数据版本。

本仓库不重复存放ECOTOOL第三方工具箱源码。

### 第三步：三人并行完成模型复现

#### 成员A：数据特征分析、ETS和Seasonal Naïve

1. 独立读取并核对原论文数据。
2. 复现Fig.1中的CO₂浓度变化趋势。
3. 分析长期趋势与季节性规律。
4. 复现ETS（AA12）模型。
5. 复现Seasonal Naïve季节性朴素预测。
6. 分别生成24个月预测结果。
7. 计算两种模型的预测误差。
8. 分析ETS与季节性朴素预测的效果差异。

重点回答：

- CO₂浓度变化有哪些时间序列特征？
- 简单的季节性朴素预测能达到什么效果？
- ETS模型是否能够更好地刻画趋势与季节性？

主要产出：

- 原始序列趋势图。
- 数据特征分析结果。
- ETS和Naïve模型预测结果。
- 模型误差及对比分析。
- 对应MATLAB代码。

#### 成员B：Airline SARIMA与Auto ARIMA

1. 独立读取原论文数据。
2. 按原文复现Box-Cox变换与差分分析。
3. 绘制差分序列的ACF/PACF图。
4. 复现Airline SARIMA模型。
5. 运行Auto ARIMA自动识别模型。
6. 检查两种模型的结构及参数。
7. 生成24个月预测结果。
8. 计算两种模型的预测误差。
9. 分析人工指定模型与自动识别模型的异同。

重点回答：

- 为什么需要对原始序列进行差分？
- ACF/PACF反映了什么信息？
- 自动识别的ARIMA模型与Airline模型是否一致？
- 两种模型的预测效果有何差异？

主要产出：

- 差分序列及ACF/PACF图。
- Airline与Auto ARIMA模型结果。
- 模型预测图。
- 模型误差及对比分析。
- 对应MATLAB代码。

#### 成员C：UC结构模型与综合评价

1. 独立读取原论文数据。
2. 复现UC（LLT12）模型。
3. 分析模型估计的长期趋势与季节性成分。
4. 尝试复现Fig.3中UC估计趋势与官方趋势的对照。
5. 生成UC模型的24个月预测结果。
6. 计算UC模型的预测误差。
7. 核对sMAPE与MASE的计算方法。
8. 在其他成员提供结果后，汇总不同模型的评价指标。
9. 分析本组结果与原论文Table 4的一致之处及差异。

重点回答：

- UC模型如何刻画趋势与季节性？
- 模型估计出的趋势是否与原论文结果相近？
- 不同模型在相同预测条件下的表现如何？
- 复现结果与原文不一致时，可能有哪些原因？

主要产出：

- UC模型预测结果。
- 趋势及成分分析图。
- UC模型误差评价。
- 跨模型比较表。
- 论文结果对照分析。
- 对应MATLAB代码。

### 第四步：统一预测结果与评价方式

三人使用相同的数据范围和评价口径，分别计算自己负责模型的预测指标。

评价指标包括：

- **sMAPE**：对称平均绝对百分比误差。
- **MASE**：平均绝对缩放误差。

每位成员输出的预测数据至少包含：

| 字段 | 含义 |
|---|---|
| model | 模型名称 |
| forecast_origin | 预测起点 |
| target_month | 预测目标月份 |
| horizon | 预测步长 |
| actual | 实际观测值 |
| predicted | 模型预测值 |

预测值和实际值应处于相同的原始CO₂浓度尺度，单位为ppm。

使用Box-Cox变换的模型需要正确处理预测值的逆变换。不同ECOTOOL函数可能具有不同的变换处理方式，必须核对，避免重复逆变换。

统一的数据格式有利于跨模型比较和结果检查。

每位成员负责计算并检查自己模型的误差。

成员C负责汇总，不需要重新执行其他成员的全部模型。

### 第五步：尝试完整滚动预测

完成单次24个月预测后，三人分别在自己负责的模型上尝试复现原论文的滚动预测。

基本过程：

1. 确定与原论文一致的初始训练样本。
2. 拟合当前模型。
3. 预测未来24个月。
4. 记录预测结果。
5. 将训练截止点向后推进1个月。
6. 使用更新后的样本重新估计模型。
7. 重复上述过程，并按照原文规则统计预测误差。

原论文报告220轮滚动预测。实际复现时需要核查不同预测步长的有效观测数量和评价方式。

三位成员分别完成各自模型的滚动预测，避免将全部计算任务集中到一人身上。

成员C在汇总后将结果与Table 4比较。

如果时间不足，优先确保单次预测正确，并在汇报中明确说明未完成的滚动预测范围，不把部分结果表述为完整复现。

### 第六步：分析结果并完成汇报

各成员分别解释自己负责模型的结果。

最后汇总回答：

1. 哪些模型能够较好地预测CO₂浓度？
2. 各模型是否优于季节性朴素预测？
3. 预测步长增加后，预测误差如何变化？
4. 本组结果与原论文有哪些一致之处？
5. 如果存在差异，可能是什么原因？
6. 本次复现有哪些局限？

结论必须基于实际运行结果。

三名成员可以分别在自己的电脑上开展实验，通过GitHub同步代码和结果。

```bash

git commit -m "简要说明本次完成的任务"

```

协作要求：

- 三人分别维护自己负责的实验脚本。
- 尽量避免同时修改同一个文件。
- 各成员保留自己的模型运行结果。

- 完成的实验代码应能够使用对应数据独立运行。
