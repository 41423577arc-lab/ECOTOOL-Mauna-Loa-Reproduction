# 成员 B：220 轮滚动预测

## 运行

在 MATLAB 项目目录运行：
```matlab
addpath('src');
run_member_b_rolling(3)    % 先验证 3 轮
run_member_b_rolling      % 继续至全部 220 轮
```
其他电脑可传入依赖路径：
```matlab
run_member_b_rolling(220,'ECOTOOL 的 fsroot 路径','dataPLOSpaper.mat 完整路径')
```
关闭 MATLAB 或中断后，重跑同一命令即从检查点继续；不要同时启动两份程序。

## 本次明确采用的协议

- 作者固定数据 CO2，723 个月，月份按 1958-03 至 2018-05 映射。
- 第 r 轮训练 CO2(1:479+r)，预测 CO2(480+r:503+r)，r=1,...,220。
- 初始训练 480 个月，逐轮扩展，最后训练长度 699；每个步长均有 220 个真实值。
- 第一轮训练截至 1998-02，目标 1998-03 至 2000-02；最后一轮训练截至 2016-05，目标 2016-06 至 2018-05。
- 论文正文将 March 1998 称为初始 origin；这里明确把最后可见训练月作为 forecast_origin，把 March 1998 记为第一目标月。日期由索引计算，避免差一月。
- 与单次示例 CO2(25:504) 不同，正式滚动不跳过前 24 个值。723-480-24+1=220。
- 每轮仅用训练集估计 Box-Cox lambda，Airline 固定结构重新估计；Auto 输入原始数据，结构和参数均重新识别。
- 当前作者工具箱 Auto.py 已为原始 ppm；只有 Airline.py 进行逆变换。
- 每轮 MASE 分母为当前训练集 12 阶季节差分绝对值均值。先计算每轮每个步长误差，再对轮次等权平均。
- metrics_by_horizon 中 h=24 为“第24步”的跨轮平均；不是前24步的累计平均。后续与 Table 4 对照时需区分论文的逐月行与年度汇总行。
- 第三方依赖沿用作者仓库提交 8de5e85af0a9ffe852a9cab71b44bfc063175cb2。

## 本机实际运行结果（2026-11-14）

已完成两种模型各 220 轮，每轮 24 步，共 10560 条预测记录。累计模型耗时约 624 秒。Python 独立核验了日期、完整轮次、有限数值、共同真实值以及 sMAPE；另用 MATLAB 从原始训练序列重新计算 MASE。

|模型|第1步 sMAPE (%)|第12步 sMAPE (%)|第24步 sMAPE (%)|第24步 MASE|
|---|---:|---:|---:|---:|
|Airline|0.085743|0.16378|0.25474|0.70962|
|Auto ARIMA|0.066814|0.13519|0.18605|0.52160|

上述是逐步长结果，非年度累计平均。误差随步长总体增加，Auto 在本次实现中总体较低。本次结果尚未严格还原 Table 4 数字，不得称为论文数值完全复现；后续需核对 Box-Cox 策略、估计选项、异常值处理及年度行汇总口径。当前每轮重估 lambda、Airline 使用 modelTF 默认 EML、Auto 使用 modelAUTO 默认 CML，异常值设置沿用所下载版本默认值，不为追求论文数值而事后挑选配置。

`checkpoint.mat` 含依赖数据快照，可用于核验和续跑；请勿手工修改。已有 220 轮检查点时再次调用函数只重新导出表和图，不会重新拟合。希望从零复跑时，先备份或重命名 results/rolling_b 整个目录再执行。
